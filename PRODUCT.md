# PRODUCT.md

**What this is:** A personal, romantic gift website Naim built for his girlfriend Batoul. A hub of heartfelt "cards" (apology, love letters, a bouquet, a travel farewell) she opens on her phone.

**Register:** brand — the design *is* the product. Emotional, cinematic, high-craft. Every page is a gesture.

**Audience:** One person — Batoul. Opens on mobile, at night, alone. The feeling on arrival matters more than any task.

**Voice:** Warm, intimate, sincere. Naim's real voice — simple honest words, not marketing polish. Nickname "mdwara" (مدورة, "full moon") throughout.

**Aesthetic system (established, preserve):**
- Night-sky theme: deep indigo/violet `#050818` → `#0f0f2e`, glowing moon, twinkling starfield, shooting stars, drifting petals.
- Warm gold/rose light: `#f8e4c8`, `#ffd6e0`, `#f8c8a0` against the dark.
- Fonts: Pinyon Script (display/signature), Dancing Script (accents), Cormorant Garamond (body).
- Motion is central: reveals, typewriter letters, blooming, floating. Should feel cinematic, never abrupt.

**Constraints:** Static site on GitHub Pages, hand-written HTML/CSS/JS per page, no build step. Mobile-first.
